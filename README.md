## دليل قطر / Qatar Business Guide
دليل أعمال وخدمات ثنائي اللغة (عربي/إنجليزي) للسوق القطري. واجهة ثابتة + خادم Node بدون أي مكتبات خارجية + SQLite.

### التشغيل
```bash
# يتطلب Node 22.5 أو أحدث
ADMIN_EMAIL=you@example.com ADMIN_PASSWORD='كلمة-مرور-قوية' npm start
# ثم افتح http://localhost:8000
npm test   # اختبارات الـ API
```
- قاعدة البيانات: `data/app.db` (تُنشأ تلقائيًا وتُملأ ببيانات تجريبية). غيّر المسار بـ `DB_FILE`.
- حساب الأدمن يُنشأ من متغيرات البيئة `ADMIN_EMAIL` / `ADMIN_PASSWORD` فقط (لا توجد كلمات مرور في الكود).
- على الإنتاج (HTTPS) فعّل `COOKIE_SECURE=1`.

### الميزات
تسجيل/دخول/خروج، تقييمات حقيقية (نجوم 1-5 + تعليق، تقييم واحد لكل مستخدم لكل نشاط، لا يقيّم صاحب النشاط نشاطه، حذف للمالك والأدمن)، إضافة نشاط (يبقى قيد المراجعة)، لوحة أدمن (قبول/رفض/توثيق)، صفحة "أنشطتي"،
بحث وفلترة، اتصال وواتساب، RTL/LTR، وضع داكن.

### الأمان
كلمات المرور بـ scrypt + salt، الجلسات بتوكن عشوائي مخزّن مُجزّأ (SHA-256) في كوكي HttpOnly/SameSite،
تحديد معدل المحاولات، رفض الطلبات غير JSON، رأس CSP صارم، حماية من path traversal.
